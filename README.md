# DeepSC MIMO Classifier

This private repository contains the final non-adversarial DeepSC MIMO diagnosis implementation and its reported results.

| Path | Contents |
|---|---|
| `deepsc-mimo-diagnosis/` | Source code, Slurm jobs, documentation, tests, provenance records and stored results |
| `adv_datasets/` | Prepared 90,746-token shared vocabulary and the Europarl, UK Hansard and arXiv datasets used by the project |

The datasets are already preprocessed and should not be prepared again. Trained checkpoints, receiver traces and the full feature table are not included; they can be regenerated by the pipeline if needed.

## Paths for a new run

```bash
cd <repository-folder>/deepsc-mimo-diagnosis
export DEEPSC_SHARED_ROOT="$(cd ../adv_datasets && pwd -P)"
export DEEPSC_RUNS_ROOT=/path/to/a/writable/results/directory
```

Only `DEEPSC_RUNS_ROOT` needs to be replaced with a suitable path on the user's account.

The project was run on the AUB Octopus cluster with Python 3.10.13, PyTorch 2.1.2, CUDA 12.1 and a V100 32 GB GPU. Technical execution and recovery details are documented in [`deepsc-mimo-diagnosis/docs/DEPLOYMENT.md`](deepsc-mimo-diagnosis/docs/DEPLOYMENT.md). For a fresh run, the documented preflight must complete successfully before the remaining jobs are submitted.

## Reported results

The stored outputs are under [`deepsc-mimo-diagnosis/results/`](deepsc-mimo-diagnosis/results/). Their relationship to the code used on the cluster is documented in [`deepsc-mimo-diagnosis/provenance/README.md`](deepsc-mimo-diagnosis/provenance/README.md).

A fresh GPU run should produce comparable, but not necessarily bit-identical, values because numerical behavior can vary across hardware and library versions.
